Passthough Mashup — Fase 1.1: Goku no mundo de Zelda

Os dois jogos continuam independentes. A posição decodificada de Goku (Legacy of Goku II) é projetada sobre a tela de Minish Cap. Esta etapa transfere apenas o estado de posição como marcador; ainda não transfere sprite, colisão ou física. A conversão entre os mundos é calibrável.

Aguardando as duas ROMs.

Host — Minish Cap

Setas = movimento · X/Z = A/B. O marcador ciano indica a posição projetada de Goku.

Provider — Legacy of Goku II

W/A/S/D = movimento · J/K = A/B. Este jogo fornece o estado de Goku para o mundo de Zelda.

Controles por toque

Use os botões na tela para jogar no celular. Cada conjunto controla somente seu próprio jogo; também é possível usar teclado físico.
